# Sistema de Gestión de Inventario

Aplicación web desarrollada con HTML, CSS y JavaScript para administrar el inventario de una tienda de tecnología, ropa y maquillaje.

## Funcionalidades

- Visualización de productos.
- Registro de nuevos productos.
- Validación de datos.
- Filtro por categorías.
- Cálculo del valor total del inventario.
- Conteo de unidades y productos agotados.
- Cambio de estado de los productos.
- Eliminación de productos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
